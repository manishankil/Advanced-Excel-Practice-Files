# Advanced Excel Practice Files 📊

Ye repository meri Excel learning journey ka record hai — yahan maine practice ke liye banayi hui files organized tarike se rakhi hain.

## 📁 Folder Structure

- 01-basics/ — cell entry, formatting, basic navigation
- 02-formatting/ — number formats, conditional formatting, styles
- 03-formulas-basic/ — SUM, AVERAGE, IF, basic functions
- 04-formulas-advanced/ — VLOOKUP, INDEX-MATCH, nested formulas
- 05-data-tools/ — sorting, filtering, data validation
- 06-pivot-tables/ — pivot tables, summarization
- 07-charts/ — charts aur visualization
- 08-dashboards/ — final dashboards

## 🎯 Goal

Excel mein proficient banna — data analysis, formulas, aur dashboards ke through.
